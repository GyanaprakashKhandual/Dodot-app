# ✅ DoDot – Frontend

A modern **Todo Management Website** built with the **MERN stack**.  
This repo contains the **frontend** of DoDot, crafted for speed, beauty, and smooth interactions. ✨

---

## 🚀 Tech Stack

- 🏷️ **Next.js** – React framework for production-ready apps  
- 🏷️ **Tailwind CSS** – Utility-first styling for modern UI  
- 🏷️ **Framer Motion** – Smooth & delightful animations  
- 🏷️ **Lucide / React Icons** – Crisp icons for better UX  

---

## ✨ Features

✅ Beautiful & responsive UI with Tailwind CSS  
✅ Animated transitions with Framer Motion  
✅ Dark/Light mode ready 🌙☀️  
✅ Task management with add/edit/delete functionality  
✅ Intuitive navigation and modern layout
